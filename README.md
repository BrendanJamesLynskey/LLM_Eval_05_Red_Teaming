# LLM_Eval_05_Red_Teaming

Comprehensive guide to red-teaming large language models. Covers threat modelling (attacker capabilities and goals), manual red-team processes and pay structures, automated red-teaming with RL-trained attackers and prompt fuzzing, the major adversarial datasets (HarmBench, AdvBench, PAIR, JailbreakBench), Anthropic's Responsible Scaling Policy, scoring refusals correctly, and building a sustainable internal red-team practice.

**Live site:** https://brendanjameslynskey.github.io/LLM_Eval_05_Red_Teaming/

Part of the [LLM Evaluations sub-hub](https://github.com/BrendanJamesLynskey/LLM_Hub_Evaluations)
